# Code of Conduct

We want Impact Check to be a welcoming, harassment-free project for everyone, regardless of background or identity.

**Expected:** be respectful and constructive; assume good intent; give and accept feedback gracefully; focus on what
is best for users and the community.

**Not acceptable:** harassment, insults or personal attacks; sexualized language or imagery; publishing others'
private information; sustained disruption; any conduct that would be inappropriate in a professional setting.

**Scope:** all project spaces (issues, pull requests, discussions) and public spaces where someone represents the project.

**Enforcement:** report incidents privately to the maintainer, Koushik Ramani ([@aiwithrk](https://github.com/aiwithrk)), EnWithAI Technologies, at [hello@enwithai.com](mailto:hello@enwithai.com). Reports are handled confidentially.
Maintainers may remove content and warn, suspend or ban participants in proportion to the behavior.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
